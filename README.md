# SCAD-Sistema-de-Cumplimiento-Ambiental-Digital
SCAD es una aplicación web para apoyar a microcomercios recicladores en la gestión de sus obligaciones ambientales. Permite registrar empresas, organizar permisos y documentos, generar alertas por vencimientos y crear reportes digitales que facilitan el cumplimiento normativo.

## Objetivo del proyecto
Desarrollar una solución digital que facilite el cumplimiento de la normatividad ambiental en México, reduciendo riesgos legales y mejorando la administración interna de las empresas dedicadas al manejo de residuos.

## Funcionalidades principales
- Registro de empresas y usuarios
- Sistema de roles (Administrador, Empresa, Usuario)
- Checklist de cumplimiento ambiental
- Gestión y almacenamiento de documentos
- Alertas de vencimientos
- Generación de reportes en PDF
- Paneles de control por tipo de usuario

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Node.js (Backend)
- API REST
- Base de datos SQL
- Git y GitHub

## Estructura del proyecto
- frontend/: Interfaz de usuario
- backend/: Lógica del sistema y API
- database/: Scripts de base de datos
- docs/: Documentación y diagramas
